# Figma parity matrix

This document tracks the implementation of the [VLC Redesign (Community) Figma file](https://www.figma.com/design/5UEUReDQz2dQjwoQDHY5z9/VLC-Redesign--Community-) by Juxtopposed. The public Figma page is not readable from this environment, so the references below use the names of the checked-in screenshots in [`docs/screenshots/`](screenshots/), not claims about exact Figma frame names. Add the exact frame names and any design-only frames after comparing with the original file.

“Implemented” here means static inspection found the view and its principal interaction in the current QML source; it does not certify visual parity or runtime correctness. The validation column gives a check to run for future changes. Playback behavior is covered in part by [`scripts/smoke-test.sh`](../scripts/smoke-test.sh), and reference captures are generated by [`scripts/screenshots.sh`](../scripts/screenshots.sh).

## Change workflow

When a UI change is made, update the relevant row if its behavior, component ownership, state or acceptance criteria changed. Regenerate the relevant screenshot when the visible result changed. Keep screenshot media attribution with the screenshot documentation in `README.md`.

For a new design screen, add a row with the Figma frame name and link when available, the corresponding QML components, implementation state and a criterion that can be checked in the running application. Record design-only or intentionally deferred work as such rather than marking it implemented.
