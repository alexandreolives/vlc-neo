# Figma parity matrix

This matrix tracks VLC Neo against the [VLC Redesign (Community) Figma file](https://www.figma.com/design/5UEUReDQz2dQjwoQDHY5z9/VLC-Redesign--Community-) by Juxtopposed. The Figma page returns HTTP 403 from this environment, so each reference below is a checked-in capture name, not a verified Figma frame name. These 21 captures do not prove that every Figma frame is represented. Add the exact frame names and any design-only frames after comparing with an accessible export of the file.

“In code” means the view and behavior are present in QML or the C++ bridge; it does not certify visual parity or runtime correctness. Validation is listed separately so captures are not mistaken for interaction tests.

The CI smoke test currently verifies playback and video output, queue contents and next-item playback, pause/resume, volume/mute, subtitle folder matching and active subtitle selection, saved subtitle delay and scale, resume availability, keyboard seeking, bookmarks, playback rate, VLC config persistence, dark and light theme captures, compact-window size, screenshot creation, and theme/accent persistence. It does not compare screenshots pixel by pixel. The separate [`scripts/screenshots.sh`](../scripts/screenshots.sh) generates the documented Sintel captures and requires the Sintel sample folder.

## Change workflow

When a UI change is made, update the relevant row if its behavior, component ownership, state or acceptance criteria changed. Regenerate the relevant screenshot when the visible result changed. Keep screenshot media attribution with the screenshot documentation in `README.md`.

For a new design screen, add its exact Figma frame name and link when available, the corresponding QML components, implementation state, current automated evidence and a check that can be run in the application. Record design-only or intentionally deferred work as such rather than marking it implemented.
