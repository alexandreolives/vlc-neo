# Figma parity matrix

This matrix tracks VLC Neo against the [VLC Redesign (Community) Figma file](https://www.figma.com/design/4JZcTRTM2ZVZdIV0S61smp/VLC-Redesign--Community---copie-) by Juxtopposed. The copy is readable by the project's direct Figma MCP connection. Its `Page 1` has 57 top-level screen frames and 46 component reference frames. The inventory below includes every screen frame; the 46 component examples are not screens and are not counted as UI coverage.

Node IDs are exact Figma IDs. Open the linked file and append `?node-id=<ID with colon changed to hyphen>` to its URL to open a particular frame. Repeated frame names are separate Figma nodes and are all listed. Some Player and Customize frames are flattened visual frames whose metadata has no child layer names; their state differences still need visual review against the captures listed below.

“In code” means the view or behavior exists in QML or the C++ bridge; it does not certify visual parity or runtime correctness. The smoke test verifies playback and video output, queue contents and next-item playback, pause/resume, subtitle folder matching and active subtitle selection, saved subtitle delay and scale, resume availability, keyboard seeking, bookmarks, playback rate, VLC config persistence, dark and light theme captures, compact-window size, screenshot creation, and theme/accent persistence. The `player_facade` CTest verifies volume clamping, mute/unmute delegation, exposed mute state, and restoring audio when setting a positive volume after mute. CI uploads dark, light and compact-window captures; it does not compare pixels. [`scripts/screenshots.sh`](../scripts/screenshots.sh) generates additional Sintel captures and requires the Sintel sample folder.

Core controls use SVGs exported from the Figma icon set, and the theme's base colors follow the exported Figma paint styles. The icon provider keeps Lucide icons as a fallback for controls that do not have a direct Figma equivalent. Sources and attribution are recorded in [`assets/ATTRIBUTION.md`](../assets/ATTRIBUTION.md).

## Change workflow

When a UI change is made, update its row if behavior, QML ownership, implementation state or acceptance criteria changed. Regenerate the relevant implementation capture when its visible result changes. Screenshots in `docs/screenshots/` document VLC Neo's current output; they are not Figma exports or pixel-diff baselines. Keep media attribution in the screenshot documentation in `README.md`.

For a new Figma screen, record the exact frame name and node ID, intended behavior, QML mapping, current implementation state, automated evidence and manual acceptance check. Treat repeated frame names as distinct nodes, and record design-only or deferred behavior instead of marking it implemented.
